# 🌟 Markdown Previewer

A lightweight, distraction-free tool designed to render raw Markdown into clean, beautifully structured, and scannable visual text. 

## ✨ Features
* **Live Rendering**: Instantly converts Markdown syntax into HTML.
* **Clean Typography**: Optimized line heights and text sizes to prevent visual fatigue.
* **Visual Elements**: Full support for crisp headers, clean tables, and bulleted lists.
* **Saves and accounts:** Fully functional saves, authentication, and links manager


## 🚀 Quick Start

1. Clone the repository:
   ```bash
   git clone https://github.com/Hfs2024/Markdown-Previewer
   ```
2. Run:
   ```
    npm install
    npm start
   ```
3. Open ```http://localhost:3000```
4. Start typing your raw Markdown to see it glow!
